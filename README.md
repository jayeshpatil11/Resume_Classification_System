The Resume Classification System is a machine learning–based project that automatically categorizes resumes into predefined job domains using Natural Language Processing (NLP) techniques. It helps recruiters reduce manual screening effort and quickly organize large volumes of resumes.

The system preprocesses resume text, extracts features using TF-IDF / embeddings, and applies machine learning models to predict the most relevant job category. This ensures faster, consistent, and unbiased resume classification.

Technologies Used: Python, NLP, Scikit-learn, Pandas, NumPy, TF-IDF, Streamlit
